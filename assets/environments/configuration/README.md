# assets/environments/configuration/

LunaLab configuration USD layers for the base environment, physics, and sensors. The scene composes these layers to configure the laboratory environment.

## Contents

- lunarenvironment_base.usd
- lunarenvironment_physics.usd
- lunarenvironment_sensor.usd

## Simulation relevance
These resources complete the local scene dependency tree; missing or relocated referenced files can prevent the environment or rover from loading correctly.
