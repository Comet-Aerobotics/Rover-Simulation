# assets/terrain/processed/

Reserved for terrain assets prepared for direct use by the simulation. Keep source elevation data in `assets/terrain/source/` so original inputs remain distinct from generated or repaired outputs.

## Contents

- `.gitkeep` preserves this currently empty destination.

## Simulation relevance

When a processed terrain asset is added, this folder provides a stable location for the scene's prepared terrain inputs. The current scene dependencies do not require a file here yet.
