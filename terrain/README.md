# terrain/

Offline terrain tools for generating a mesh from source DEM data, repairing collision properties on a separate stage copy, and validating terrain structure.

## Contents

- __pycache__/
- generate.py
- processed/
- repair.py
- validate.py

## Simulation relevance
This folder supports the selected LunaLab/Jackal simulation; the purpose above describes its specific role and ownership boundary.
