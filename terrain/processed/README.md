# terrain/processed/

Reserved for outputs produced by the offline terrain generation, repair, and validation tools. This is where generated terrain artifacts belong; source DEM files remain under `assets/terrain/source/`.

## Contents

- `.gitkeep` preserves this currently empty output folder.

## Simulation relevance

Generated terrain may be staged here before it is copied or referenced by a saved scene. No current simulation output is stored here, so the repository retains the clean destination without checking in generated artifacts.
